# Probadores · Tienda Rincón Sur

App móvil interna para el personal de tienda: muestra qué probadores están
libres, ocupados o excedidos, cuánto tiempo llevan y cuántos clientes esperan,
y avisa cuando un probador supera el tiempo límite.

Proyecto académico DSY1105 (Desarrollo de Aplicaciones Móviles). Datos ficticios.

## Integrantes
- Nicolás Rojas Barría
- Elvira San Martín

## Tecnologías
Kotlin, Jetpack Compose, Material 3, MVVM, Room.

## Funcionalidades planificadas
- Login con validación por campo
- Panel de probadores con estados y cronómetro
- Detalle del probador y registro de prendas
- Reporte de prenda olvidada con fotos (cámara)
- Alertas con notificación y vibración

## Estado actual
Base del proyecto en MVVM lista. En desarrollo: navegación, formularios,
Room y recursos nativos. Mockups de la propuesta en `docs/mockups/`.
